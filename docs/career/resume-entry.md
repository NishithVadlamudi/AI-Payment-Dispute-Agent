# Resolve — AI Payment Dispute Agent
Next.js · TypeScript · Gemini tool use · Neon Postgres · PostgREST · Vitest · Docker
[GitHub](https://github.com/NishithVadlamudi/AI-Payment-Dispute-Agent) · [Live demo](https://resolve-payments.onrender.com/payments)

- Built a payment-investigation agent and dashboard with Next.js, typed Gemini tools and human refund approval, improving the key-free regression suite from 131 to 194 passing checks.
- Built database-enforced mock refund limits, idempotency and persistent evaluation storage with Neon Postgres, improving the isolated Neon integration suite from 29 to 35 passing checks.

These before/after figures describe executed test counts, not code-coverage percentages or model-accuracy gains. All payments are fictional. See docs/first-run-notes.md and docs/provider-debugging.md.
